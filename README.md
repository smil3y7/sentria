# Sentria — Hub

Central hub for the Sentria ecosystem: a modular set of tools for dream
exploration, lucid dreaming, symbolic continuity, and reflective
consciousness research.

**Live:** https://sentria-navy.vercel.app/ *(placeholder — update once the
final domain is live)*

---

## What's in this repo

This repository **is** the deployed site — everything in it is served
directly by Vercel as static files. There's no build step on Vercel's side;
what you upload here is exactly what visitors see.

```
/
├── index.html          ← homepage (constellation UI, app cards, signup)
├── about.html           ← About page (English)
├── privacy.html         ← Privacy policy (English)
├── contact.html         ← Contact page
├── sl/
│   ├── about.html        ← About page (Slovenian)
│   └── privacy.html      ← Privacy policy (Slovenian)
├── logo.png
├── favicon.png
├── screenshots/
│   ├── journal.png
│   ├── atlas.png
│   └── ...
├── robots.txt
├── sitemap.xml
└── README.md            ← this file
```

## Tech stack

- Plain HTML, CSS, and JavaScript — no framework, no build tools required
  to run the site itself
- Hosted on **Vercel** (Hobby plan), auto-deploys whenever files change
  in this repo
- Fonts loaded from Google Fonts (Cormorant Garamond, DM Sans, DM Mono)
- Forms (newsletter signup, contact) handled by **Formspree**
- No backend, no database, no build pipeline on the Vercel side

## How this site is updated

Changes are pushed via the **local git CLI** (`git add`, `git commit`,
`git push`) from your machine. Vercel is connected to this repo and
auto-deploys on every push to the main branch, usually within a minute.

**Important for multi-file changes:** if you're editing something that
touches more than one file at once — for example both `index.html` and
a shared asset — commit and push all the changed files together in the
same commit. Pushing them separately can leave the live site in a
half-updated state for the few seconds between deploys.

## About and Privacy pages are bilingual

Unlike the homepage and contact page (which use a JavaScript-based language
toggle), `about.html` and `privacy.html` exist as **separate real pages**
per language — `/about.html` (English) and `/sl/about.html` (Slovenian) —
so each language is independently indexable by Google.

These two pages are generated by a small local build tool (the
`sentria-build` project, kept separately on your machine, not in this repo)
rather than hand-edited directly. That tool has its own README covering how
to edit their content and regenerate them. Once regenerated, commit and
push the output here the same way as any other file.

Every other page on the site (homepage, contact) is still edited directly,
by hand, in this repo.

## Adding a new module to the hub

The homepage's card grid and constellation are built to make this easy:

1. Open `index.html`, find the `<!-- ADD NEW APP -->` comment near the
   bottom of the cards grid
2. Copy an existing `.app-card` block, update its name, tagline,
   description, link, and screenshot path
3. Add a matching `.hero-node` entry near the top of the file so it shows
   up in the constellation visualization too
4. Add a screenshot to `screenshots/`
5. Add translation strings for the new module in the `TRANSLATIONS` object
   near the bottom of `index.html` (both `en` and `sl` blocks)

## Known limitations (by design, for now)

- The homepage and contact page use JS-only language switching, so only
  one language is indexable by search engines for those two pages. The
  About and Privacy pages don't have this problem (see above).
- Several ecosystem modules (Somnia, Orbis, Limina, etc.) are separate
  projects with their own repos and Vercel deployments — this hub only
  links out to them, it doesn't contain their code.
